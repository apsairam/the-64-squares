# The 64 Squares — 10/10 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the current art-led chess landing page into a source-backed, beginner-friendly, accessible, fast chess information site without losing its monochrome cinematic identity.

**Architecture:** Keep React 18 + Vite on the client and Express on the server. Replace the pinned introduction's chapter crossfade with a coherent eight-step Scholar's Mate lesson on a square, coordinate-labelled board. Add a persistent navigation header, a compact "Learn" reference, modern chess history, and a sources/method section. Harden accessibility, delivery, metadata, and tests.

**Tech Stack:** React 18, Vite 6, GSAP/ScrollTrigger, Express 4, Playwright, Node test runner.

**Spec:** The evaluation in the conversation (strict 6.5/10 review) is the requirements source. No separate spec document.

## Global Constraints

- Preserve the monochrome/archive visual language, chrome 3D section pieces, and scroll-driven personality.
- Primary audience: curious casual players and people who appreciate art; the site must work as both a story and a beginner reference.
- Every chess claim must be either sourced, clearly marked as tradition/uncertain, or corrected.
- WCAG 2.2 AA baseline: body text >= 16px, small labels >= 12px, normal-text contrast >= 4.5:1, interactive targets >= 44px.
- `prefers-reduced-motion` must provide a complete static/step-through experience, not a dead story.
- The board used for instruction must have square cells and visible coordinates.
- Existing keys, APIs, and the Chess.com challenge must keep working.
- No git repository exists; verify each task with commands instead of commits.

## Review Focus

- A first-time visitor arriving at 390px wide must find the rules and reach a section without fighting the intro.
- A keyboard/screen-reader user must be able to skip the intro, step through Scholar's Mate, and read the move explanations.
- A chess-literate reader must find the corrected Immortal Game notation, square board geometry, and source notes.
- A reduced-motion user must be able to see each Scholar's Mate step and the final mate.
- A production request for a missing asset must not return the SPA with HTTP 200.
